# Java Algorithm Visualizer — Shortest Path & CPU Scheduling

Ứng dụng desktop Java (Swing), dùng Maven, minh hoạ trực quan các thuật toán:

- **Đường đi ngắn nhất** (`GUI/DuongDiNganNhat.java`)
- **Lập lịch CPU** (`GUI/LapLichCPU.java`)

Điều hướng giữa các module qua màn hình quản lý (`GUI/Manage.java`).

## Chạy thử

```bash
mvn compile exec:java -Dexec.mainClass="GUI.Manage"
```

Hoặc mở project bằng NetBeans/IntelliJ và chạy trực tiếp.
